---
name: Maintenance notice scope
description: Which users maintenance mode affects and how student-facing notices should be sent.
---

Students cannot file requests, so maintenance mode only affects staff intake. Do not add a student-facing maintenance banner or status notice; if students need information, use a normal Announcement.

**Why:** The user clarified that maintenance only affects staff intake and that a normal Announcement is the preferred student communication if needed.

**How to apply:** Keep maintenance status and banners scoped to staff workflows. Use the existing announcement feature for student communication instead of changing maintenance-mode behavior.
