---
name: Student request permissions
description: The user's scope rule for request creation in student accounts.
---

Students can track their requests in their account but cannot submit a request. Preserve staff request creation.

**Why:** The user explicitly requested removal of the "Submit a Request" feature from student accounts.

**How to apply:** Do not add student submission forms or shortcuts. Enforce the restriction on the server as well as in the student portal, while preserving existing requests and tracking.
